# 固定下单（随机8码）多种子验证结论

**日期**: 2026-09-13
**方案**: 随机8码 · 倍投 10/10/10/20/20/20 · 6期周期 · 47赔率 · 6期未中暂停等开出
**数据**: 2022-01-01 ~ 2026-09-13，共 1717 期
**脚本**: `multi_seed_test.py`（多种子样本内分布）、`out_of_sample_test.py`（样本外验证）

## 一、多种子样本内分布（100组种子）

| 指标 | 数值 |
|---|---|
| 正收益种子 | 26 / 100 |
| 负收益种子 | 74 / 100 |
| 平均盈亏 | **−4514 元** |
| 中位数 | −4220 元 |
| 最好 | +20250 元（seed=69） |
| 最差 | −25930 元（seed=79） |

正收益种子的共同特征：命中率偏高（68%~73%，理论 65.7%）——是随机种子碰巧生成的8码序列与历史数据"相性好"，属过拟合。

## 二、样本外验证（关键证据）

训练段 2022-01-01~2024-12-31（1096期）选种子 → 验证段 2025-01-01~2026-09-13（621期）检验：

| 训练段Top10种子 | 训练段盈亏 | 验证段盈亏 |
|---|---|---|
| 77（冠军） | +15080 | **−1180** |
| 69 | +15040 | **−12530**（命中率跌至53.2%） |
| 47 | +12130 | −960 |
| 48 | +9750 | −8600 |
| 49 | +9740 | +2650 |
| 7 | +9390 | −7230 |
| 74 | +7170 | +6070 |

- 训练段冠军 seed=77 在验证段**转亏** −1180 元
- 训练段 Top10 中 **6/10 在验证段亏损**，无延续性
- 全100组验证段：正收益 46/100，平均 −114 元，中位数 −130 元

## 三、结论（铁律口径）

1. **换随机种子无法改变负期望**。期望 = 47/49 − 1 ≈ −4.08%，与种子无关。
2. **样本内赚钱的种子是过拟合**，样本外必然回归均值——训练段冠军到验证段转亏，直接证伪。
3. 暂停机制能小幅抬升命中率（66.4% vs 理论65.7%），但不足以翻转 −4% 的结构性劣势。
4. 任何"某组随机8码能盈利"的结论，未经样本外验证均不可采信。

**务实下一步**：随机8码+倍投的负期望是数学结构（47赔率<49号码），非参数能救。若要坚持8码方向，唯一出路是提高单号命中概率到 >1/49（需引入有统计显著性的选号信号，且过样本外关），而非换种子/换倍投。
