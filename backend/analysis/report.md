## 四、核心结论

1. **全仓(100%)百万收益是破产重置假象**：破产 98~115 次，收益来自"无限注资"。
2. **当前 ge4 的 +8864 实为亏损**：累计注资 23463 元，扣注资后真实 −14599。
3. **净收益 Top15 里 11 个时间分段翻转（过拟合）**，只有 3 个前后 EV 都为正的"稳定候选"：
   - **top5_eq2（前5信号 + 票数=2）**：前半 +1.73 / 后半 +2.46，最强，均号数 8.6
   - **top5_ge2（前5信号 + 票数≥2）**：前半 +0.75 / 后半 +0.92，偏弱，均号数 11.4
   - **top20_eq1（前20信号 + 票数=1）**：前半 +0.28 / 后半 +0.06，极弱
4. **即使 top5_eq2 稳定，也是 127 期（前后各 64 期）小样本**，需 300+ 期数据复核才敢下结论。
5. **若硬要试**：只可 ≤5% 小仓位，且优先盯 top5_eq2。
