# 自主跟踪 · AI 寻优论证报告

> 生成于 2026-09-10 | 数据 617 期（2025-01-01 ~ 2026-09-09）| 赔率 47 | 等额每号1元

## 一、功能定位

维度统计新增「自主跟踪」tab：**方案论证记录库 + AI 寻优 + 前向跟踪闭环**。

- 方案按 `scheme_key`（维度集合 + 信号口径 + offset + window 规范化哈希）去重，**避免重复论证**
- AI 枚举维度子集 × window × offset，统一回测 + 显著性检验，达标转前向
- 前向固化：每日对稳定方案固化下一期选号 → 开奖结算 → 回填 fwd_* 指标

## 二、寻优范围与口径

| 项 | 值 |
|---|---|
| 维度子集候选 | 20 单维 + TRACKABLE_DIMS 9维的2维组合(36) + 5 现有 scheme = **61 个** |
| window | 60 / 90 / 120（3 个） |
| offset | -2 / -1 / 0 / +1 / +2（5 个） |
| 总候选 | **915 种** |
| 信号口径 | 高位触发：标签遗漏 gap ≥ 近 window 期历史最高 − offset |
| 结算 | 单期单次买，赔率47，等额每号1元 |
| 无前视偏差 | 用截至上一期数据选号，当期开奖结算 |

## 三、四层判定（层层收紧，防过拟合）

1. **4 段稳健性**：4 段 EV ≥3 段为正。
2. **样本量约束**：触发期 ≥100（样本少的高 alpha 是波动假象）。
3. **统计显著性**：二项检验（命中率 vs 随机基准 N/49）+ BH-FDR 校正。**FDR 显著 = 0 个**。
4. **弱信号分级**：未校正 p<0.1 且均号<20（排除二元维度）→ 前向观察。

## 四、头数参数深挖（关键发现）

对「头数」做 offset(-6~+3) × window(30~120) 网格扫描 + walk-forward 前向验证：

1. **头数是跨参数稳健的真信号**：window 30~120 × offset -6~+2 大部分 alpha 为正，形成平滑正区域。
2. **⚠️「window=90/120 更强」是假象**：深挖发现 w=90/120 时回测 alpha 高达 +8%，但 walk-forward 前向命中率跨 window 都稳定在 ~28%（w=60 的 128 期 vs w=90 的 85 期 vs w=120 的 72 期）——**alpha 虚高是样本减少的波动，不是真增强**。
3. **头数真实前向超额稳定 +5~6%**（命中率 ~28% − 随机基准 11/49≈22.4%），与 window 无关。
4. **「头数+春夏秋冬」是负优化**：负 offset 区 alpha 转负，春夏秋冬拖累了头数。

## 五、票数阈值 ge2 · 高共识号（新信号类型）

扩展选号规则：union（憋高位标签并集）之外，新增 **ge2**（只买被 ≥2 个维度同时憋高位覆盖的「高共识号」）。

- 8 个 ge2 方案进弱信号，特征：**均号仅 1.6~4.5**（精准选号，非买一半）
- **8 个前向命中率全部超随机**（无一翻负，比 union 更稳健）
- 最强：「生肖+头数 off+0」买 1.89 个号，前向命中率 10.0%（随机 3.9%），前向二项检验 **p=0.008 显著**（全场第一个 p<0.05）
- 次强：「尾数+大小单双 off+2」前向 13.4%（随机 8.0%）p=0.064、「生肖+头数 off-1」p=0.067

⚠️ **多重比较警示**：p=0.008 是单方案未校正值，1530 种方案里找出的，可能是运气（1530 个里期望 ~12 个 p<0.008 假阳性）。仍需部署后真实样本外数据最终确认。但 ge2 高共识号是**新的、可继续挖的信号口径**。

## 六、核心结论

1. **严格 FDR：0 显著**——不能下「可盈利」结论，回测高收益是多重比较假阳性。
2. **⚠️ 时间分段审计修正了旧结论**：「头数」单维信号**单调衰竭**（4 段 EV 1.17→0.80→0.50→0.06，后半段独立回测翻负），是**前半段伪信号**，已降级淘汰。旧报告「头数是唯一稳健真信号」**作废**。
3. **真正跨时间稳健的是多维度组合**：
   - **生肖+头数 ge2**：前半 +2.9% → 后半 +4.9%，命中率稳定 2 倍随机，最稳健
   - **头数+红蓝绿肖 union**：前后半都 +5~8%，稳健
   - **头数+春夏秋冬 union**：前后半都 +4%，稳健
4. **稳健性口径修正**：必须用「后半段独立回测 alpha」（fresh start），不能用全量回测的 `back_alpha`（2 分段会把「第 3 段正+第 4 段衰竭」平均掉，掩盖单调衰竭）。
5. **淘汰门槛已落地**：扫描 + 存量重审都加「后半段独立回测 alpha≤0 即淘汰」，防跟踪伪信号。
6. **三维组合 + ge3 已扩展**：时间分段审计发现二维组合比单维跨时间更稳健，三维（C(9,3)=84）是自然延伸。
7. **真正裁决仍需部署后样本外数据**：cron 每日固化已开始，几周后真实未来数据最终确认。
