# 8码下注方案系统扫描 — 比例 × 方式 × 周期

**日期**: 2026-09-14
**脚本**: `bet_plan_scan.py`、数据 `bet_plan_scan.json`
**数据**: 2022-01-01 ~ 2026-09-14，1718 期，20 种子取平均

## 一、方案空间

8 种下注比例 × 3 种周期(K=4/6/8) × 2 种暂停(有/无) = **48 种方案**。

下注比例（6期每号金额）：等额10 / 当前10-10-20 / 温和递增 / 倍投折中 /
激进倍投(10-20-40-80-160-320) / 递减 / 前重后轻 / 斐波那契。

## 二、核心结论

**48 种方案平均盈亏全部为负（0 个转正），范围 −2610 ~ −27541。**

| 规律 | 数据 |
|---|---|
| 下注比例不改期望 | 等额到激进倍投，平均盈亏从 −2610 恶化到 −27541 |
| 越激进方差越大 | 标准差从 4124(等额) 膨胀到 100436(激进倍投) |
| 激进倍投是陷阱 | 最好种子能 +147740，但 20 种子平均 −19263 |
| 暂停略优 | 止损暂停比不暂停普遍少亏 |
| 短周期略优 | K=4 比 K=6/8 亏得少（止损更快） |

## 三、最"稳"方案（若要娱乐，选亏最少波动最小）

| 方案 | 平均盈亏 | 标准差 | 最好/最差 |
|---|---|---|---|
| **等额10 + K4 + 暂停** | −2610 | 4124 | +5530 / −8950 |
| 等额10 + K8 + 不暂停 | −2764 | 6993 | +11160 / −16490 |

## 四、数学本质（不可推翻）

赔率 47 < 号码 49，单号期望 −4.08%。下注金额序列只改变**方差**（波动），
不改变**期望**——这是鞅理论，任何倍投/递减/斐波那契都无法翻转负期望。

激进倍投的高收益（最好种子+14万）是**幸存者偏差**：它同时带来 −31万的极端亏损，
20 种子平均仍是深负。

## 五、结论

「8码 + 任何下注方案」在 47 赔率下都无法盈利。若坚持娱乐，选**等额10 + 短周期 + 止损暂停**，
亏损最慢、波动最小。盈利方向只有两个：赔率 ≥ 50 的盘口，或换数据源找真信号。
